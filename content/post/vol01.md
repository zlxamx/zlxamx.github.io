## 核心板块

**极简主义最大的对手可能是惯性**

星期四晚上，我在家里如火如荼的用 Claude Code 打造我的信息源管理软件，Vibe Coding 是我最近接触的一个崭新领域，一上手，我就着了迷，因为 Vibe Coding 给人一种自己正在创造一件东西的成就感。

但是，当我把软件的基本功能做好之后，准备进一步完善软件时，我陷入了困难。因为我原本设计好的需求都已经满足了，如果我要进一步丰富这个软件，那我就要进一步发挥自己的思考能力和创造力，才能不停的决策。

到了晚上十点钟的时候，我的头已经因为长时间高频的决策开始痛了，忽然一下子，我好像就坠入了深渊，我觉得我不想搞了。

对，我不想搞了，我想放弃，或者就此作罢，现在的东西又不是不能用。

**这个念头冒出来的一瞬间，我觉得熟悉。**

学习的时候，我觉得自己现在的水平还过得去，现实也没有发展到我一定要去学习新东西的地步，我就不想学。减肥健身也是一样，我现在也没有胖到不可以接受的程度，所以也不努力。**对于任何没有发展到不得不改变的事情，过去我总是无法投入专注力在其中。**

我以前一直以为这是意志力的问题，但那天晚上躺在椅子上的时候，我忽然觉得它更像是一种惯性。**不是我不想变好，而是维持现状就像是一双无形的大手**，它让我觉得一切还过得去，让我对冗余变得无感，让我逐渐丧失了辨别重要与不重要的敏锐度。

想到这里我觉得有点意外，因为我一直认为极简主义的最大对手是消费主义或者物欲。但物欲是显性的，容易被我们发现和对抗。**惯性却是隐形的，它不推着你去买什么、要什么，它只是让你停在原地，觉得现在这样就挺好的。**

每当我经历情绪高昂又忽然感到失落，最终选择妥协的时候，**我就丧失一次改变自己的可能性**。过去有太多次这样的时刻了。

那天晚上我没有关掉电脑。我重新坐起来，继续写了一个小时。不是因为我克服了什么，只是因为我第一次看清了那个拉住我的东西是什么。

## 轻量板块

**关于健身**

最近一周时间，我尝试了一种新的饮食方式。可以理解为轻断食，但要比轻断食的程度重一些。

早餐我依旧是选择燕麦+鸡蛋+无糖豆浆。中午饭随便吃点家常菜，尽量少油。最大的变数是晚餐，我选择了不吃或者只喝一杯蛋白粉液断。

我想这是一种很多人都在尝试的饮食方式。但我想分享的其实不在于我饮食的改变，**而在于我是如何做到的。**

以前我也尝试过几次在晚上进行断食或者液断，但最终都失败了，因为我过去二十多年的饮食习惯都告诉我，我晚上必须要吃饭，所以一旦我晚上不吃饭，不仅会觉得饿，还会觉得浑身不舒服，就像是有什么必须做的事情没有做一样，浑身刺挠。

而我这一次是如何做到的呢？其实很简单，就是给晚上的自己找点事情干。以前每到晚上，我总找不到事情做，我总在各式各样的事情里把时间度过了，打打游戏、刷刷手机、看看电脑，左一件事右一件事，好像什么都在做，但却觉得什么都没做。

在这种状态下我就会想到自己还没吃晚饭，然后总琢磨着要吃点啥，最后就不可避免吃了一顿油脂丰富的晚餐。

而对于晚上，一顿油脂丰富的晚餐，无疑是对第二天早晨体重的重大挑战。

**所以，想要控制自己的食欲，不妨解决掉自己的空闲时间。**

我拿这些时间来阅读文章、写文章、和 AI 聊天、Vibe Coding。做什么不重要，重要的是你能沉浸其中，时间很快就过去了。

唯一不好的就是，最近我晚上会觉得很饿，很饿。
