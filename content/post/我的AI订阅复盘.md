今天一天时间，我接连订阅了两个AI，回过头来才发现，原来我已经在不知不觉间订阅了这么多个AI模型了。

## Claude

Claude是我现目前最爱用的模型，订阅的级别是 Pro，每个月 20 美元。

它的缺点很少，除了 Anthropic 公司本身的国际立场问题和价格问题之外，Claude 堪称是完美的AI模型。

- 在 Chat 上，Claude 的对话风格和 Gemini 和 ChatGPT 都有所不同，它比较严肃，更多的时候不是个夸赞者，而像是个教练，和它交流很多时候都能产生新的洞见。

![](/Screenshot_20260424_193014_com_ruguoapp_jike_PersonalGalleryPictureActivity_edit_33259732834944.jpg)

- 它的中文处理能力很好，并且大部分时候言简意赅，很少有逻辑漏洞。
- 在 Claude Code 上，谁还能怀疑现在这个宇宙中最好的 Coding 产品？我用 Claude Code 从 0 开始搭建起了我的博客，并且还开发出了一个较为成熟的产品。
- 在审美上，Claude 的能力是极佳的。如果说 GPT 的编码能力能和 Claude 不相上下，那么在审美上，两者之间却有云泥之别。

简单来说，Claude 之所以能够独树一帜，一方面是因为它的基础实力，另一方面则是因为它的审美能力。

所以，如果让我只向别人推荐一个AI模型，那肯定是 **Claude OPUS 4.7**。

## Gemini

Gemini 我有一年的 Google Pro 权益，这是去年 Google 所赠送的学生权益。

虽然有这么长时间的 Pro 权益，但是最近两个月以来，Gemini 的使用频率已经大大下降了，现在我基本只用它来询问一下基础问题，分摊 Claude 的词元使用量。

但是不得不承认，Gemini 的研究功能非常好用，给它一个研究题目，它能在几分钟内给一个详细的研究报告，非常夯实。

而 Google Pro 权益不只作用在 Gemini LLM 这一个大模型的身上，同时我也可以用 Google 的 NoteBookLM 产品。

总的来说，我认为 Gemini 不算差，它是个很好的研究员，用来询问日常问题非常好用，但是在深度交流思维碰撞的领域，还是 Claude 更加权威。

## ChatGPT

这是我今天才订阅的，主要目的是为了前两天更新的 image-2 图片生成模型。

这两天这个模型在 AI 圈子里面已经流传甚广，它的能力也在流传中变得神乎其神。

好在是不需要订阅，也可以有限地免费使用这个模型来生图，我也小试了一下，的确很好，然后我用免费的额度对我的博客首页进行了重新设计，仅仅只是一稿，就让我眼前一亮。

我直接把图片展示出来，让大家更直观地感受到这个模型的强大之处。

这是我博客首页原本的设计：

![](/之前.png)

而这是 ChatGPT image-2 模型读取之后为我设计的样子：

![](/设计1.png)


你不用着急说是之前好看还是之后好看，因为审美这个东西因人而异，而真正应该注意的，应该是我仅用了一句「请根据我的博客，重新设计主页」作为提示词，就在一分钟之内收到了一个可用的设计。

这就是这件事情最夸张的部分，不是它的能力有多厉害，也不是它的速度有多快，而是这样的能力和变革，用一种人几乎感觉不到的形式发生了。

我用这个方法把我的整个博客从头到尾重新设计了一遍，而整个过程没有超过十分钟。

完成之后，我坐在椅子前，脑子甚至都还没有反应过来，心想：

这就结束了？

是的，任务结束了，但是这件事情对现有流程的冲击还远远没有结束。

如果我没有接触AI，或者说把时间倒退回十年前，我如果想要在没有学过美术和设计以及编程的基础上想要拥有一个功能完善的博客，并且还要做一套我认为可以接受的设计，我应该怎么办？

我想答案是我根本不可能办到，因为我连编程都不会。

而假设我会编程，我做出了我自己的博客，但是在设计上，我除了自己去培育我的审美和学习设计方面的知识之外，还有一条路是，我得去找个设计师。

而找个设计师，往往意味着成本的增高和时间的累计。

一个设计师设计一个完整的博客要多少时间？这个我不是很清楚，但是我知道，如果我找了一个真人设计师，把需求告诉了他。然后他十分钟不到就交了成品给我，我一定会怀疑他这份服务的价值。

是的，以前很多时候，时间都是衡量价值的尺度。但是现在，不是人，是AI，它十分钟就能给我一个方案，这让我还如何用时间来衡量呢？因为它的确是给了我一套可用的设计，它的使用价值本身存在，并不受它的工作时间的影响。

所以，这就是 AI 发展的恐怖之处。

## Deepseek API

我在我的博客里构架了一个 Agent，浏览我的博客的人可以在其限制范围内自由对话，这是我 Vibe Coding 以来唯一一个较为满意的作品。

而集成在网页里的 Agent，要有一个内置的 AI API，为了方便国内的用户使用，我选择了 Deepseek 的 API。

作为 AI 国产之光，Deepseek 的 API 便宜大碗，最终输出的质量也非常可用，现目前用起来非常舒心。

## MIMO-V2.5-Pro

这是我今天订阅的第二个模型，它是小米旗下的产品。

我之前从来没有用过国产模型来 Coding 过，今天看到卡兹的推荐，于是就订阅了一个最便宜的 Token Plan Lite，三十元。

但是在订阅之前，我就发现了一点不对劲——MIMO 的这个 Token Plan 里写的东西不是 Token 量，而是一个叫做 Credits 的东西。

难道小米还创新了一种区别于 Tokens 的东西？不过我没有多想，先订阅了，订阅完了用起来了，又在网上充了会儿浪才发现，这个模型的消耗速度很快。

心态崩了。

随着我今天的实测，我发现的确是这样。

Lite 会员给我的 60,000,000 Credits 套餐月总量，到我写文章的现在已经消耗了 59%，在容量达到 60% 的时候，小米还贴心地给我发来短信，叫我记得及时补充。

那么我用来做了什么呢？

其实就做了一件事：在我的博客 Agent 问答工具里面新增了一个聊天记录导出为图片的功能，然后就是设计和修改这个图片模板。

我用 GPT 已经设计了一个模板发给它，但是它的阅读能力好像很差，一直都无法改出让我满意的，唯一的优点我认为是它的处理速度倒是蛮快的。

工作很麻利。

而做这么一点事情就用了一个月 60% 的总量，这价格我是真心有点用不起。

所以用完了之后，我应该是不会再继续用了。

不过现在国产模型也是群雄并立，还有很多模型我都没有用过，例如 KIMI、GML、minimax 等。

AI 的发展如火如荼，日新月异，几乎每天都有新概念，新技术，新焦虑。

不论是国内还是国外，都是模型林立竞争激烈。

我不禁有一种思考，AI 的发展到最后，市场会是什么样呢？会不会和大多数行业一样，诞生一家在市场中有绝对统治力的公司？包揽大多数的客户？

我无法预测，但现目前来看我觉得很难。因为就国外的 AI 模型来看，它们并非孰强孰弱，而是在各自擅长的领域独树一帜。
操作系统竞争最终走向少数寡头（Windows + macOS + Linux），但餐饮市场永远是川菜、粤菜、日料共存，没有「统治级」的单一选项。AI 模型竞争更接近后者——因为用户选择 AI 的理由不是「谁最普及」，而是「谁最对我胃口」

操作系统在经过这么多年的发展之后，只剩下了少数寡头（Windows、Macos、Lunix），但是餐饮市场却永远是各大菜系共存，没有谁统治市场这种说法。

而AI的发展和竞争，我认为就类似于餐饮。

因为我们都在凭着口味做选择，而不是谁开的店最多。
