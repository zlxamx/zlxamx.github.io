## 研究和实践 AI 的使用

### 研究

这一周接触了一个国外的模型和两个国内的模型。

#### ChatGPT Image-2

这是最近刚发布的一个图像生成模型，在生图方面有非常惊人的表现，然而我和梁某银都拿它来走了歪路，直接用它做了博客的设计。

#### Mino-V2.5-Pro

国产模型之一，小米旗下的品牌。我花费了 30 元订阅了它的 Token Plan Lite，套餐里包含的额度现在基本已经用完了。

#### Deepseek-V4-Pro/Flash

深度求索这周发布的新模型，我也已经用上了。

#### 在 Claude 中使用第三方 API

我听闻 Claude 的客户端里已经可以用上第三方的 API 来使用 Claude Code 了，为此我很高兴，所以我立刻就研究了起来。

因为原来如果想要在 Claude Code 中接入第三方的 API，只能在终端里使用，而我其实不太爱使用终端，原因也很简单，我觉得客户端才更符合现在的使用逻辑，设计美观，操作方便。

最关键的是，在客户端里进行 coding，可以方便地管理过往的任务，我喜欢把不同方向的任务放在一个聊天记录里进行操作。

### 实践

#### ChatGPT Image-2

在用了两天免费额度之后，我开通了 ChatGPT 的 Plus 权益，然后用这个模型从头到尾设计了一遍我的博客，现在我的博客相比起一周前，已经脱胎换骨了。

我使用下来，这个模型有几大优点：

- 第一，**它很聪明**。能听懂我说的话，能够根据需求精准出图。
- 第二，它很快。只要把相关的要求或者底稿发给它，它可以在很短的时间里返图，基本不需要第二次修改。
- 第三，额度很多。我不知道 ChatGPT 的 token 额度在哪儿看，但是在最近的使用里，在使用强度不大于 Claude Code 的情况下，我从来没有碰到过五小时额度墙，难道 ChatGPT 不存在五小时额度墙这个东西？

但是它还是有一些问题：

- 第一，在 Chat 中会莫名其妙调用生图模型。例如我上传了一张图片，然后提示词中明确说明，我应该如何编写提示词，不要调用生图模型，它还是会直接给你生成一张图片，对此我感到很无语。
- 第二，在对图像进行二次修改的时候容易卡死。有时候图片还是会有一些细节上的瑕疵，例如一个杯子存在两个杯把，当我用画笔选中并要求它消除这个杯把的时候，会有概率卡死，不过好在卡死之后重新回到界面还是会得到想要的结果。
- 第三，每次对一张图片进行重新编辑，就会生成一个单独的聊天记录，这会导致我堆积起来非常多的聊天记录。至今为止我好像从来没见到过哪家 AI 在聊天功能里面做过聊天记录文件夹之类的功能，这难道是违背了什么逻辑吗？还是 AI 公司更希望用户删除聊天记录或者归档？

#### Mimo-V2.5-Pro

坦白说，对于这个模型，我都不知道写什么实践记录，因为这个过程实在是太快了。

Lite 计划中赠送的 credits 我不知道对应多少 token，但是我根本没有做什么项目，就已经花完了。

现在让我回忆我用它来具体做了什么，我都凑不出一个完整的工作流。

- 在我的「唯物辩证法问答工具」里，我用它做了一个图片分享的功能，然后设计了一个半成品图片模板。
- 用它检查了一下我的代码库，删除了一些垃圾代码。

就是这样，然后就没有了。

这个模型给我的印象是 token 花得太快了，好歹我也是充了 30 块钱。

同样的工作，如果我用 Sonnet 来做，也许连五小时限额都摸不到，而在 Mimo 这儿我已经用了一个月的额度了。

更重要的是，它的工作能力我认为也一般，我不是专业的程序员，但是我先后用过 Sonnet、Opus、Codex 等模型，包括最新的国产 Deepseek V4 也用过，它们的工作都比 Mimo 要强一些。

#### Deepseek-V4-Pro/Flash

看到深度求索发布新的模型，其实我是非常开心的，因为**深度求索的 token 在业内是出了名的便宜大碗**。

更重要的是，我的「唯物辩证法问答器」项目就是基于深度求索的 API 来做的，原来只能用 Deepseek Chat 模型来进行对话，输出质量其实还行，但是看到 Deepseek V4 的性能报告之后，发现它的能力完全不输 Claude 的 Sonnet，我更开心了。

所以我第一时间就尝试着把我的 API 模型换成了 V4 Pro，但是在测试了半个小时之后，我发现我的产品不太适合 Pro 模型。

因为这个问答器是集成在网页上的，而 V4 Pro 不仅消耗的 token 量比较大，思考时间也会很长，问它一个较长的问题，常常碰到时长壁垒，这样对使用体验非常不好，所以最后我还是换成了 V4 Flash。

Flash 对比 Pro，速度提升了非常多，并且回复质量对比 Deepseek Chat 也提升了很多，为此我感到非常兴奋。

除此之外，我也把 V4 Pro 模型接入到了 Claude Code 里面，已经使用 V4 Pro 进行了一段时间的 coding，表现让我非常惊喜，报告里所写的「不弱于 Sonnet」是完全成立的，工作落地率非常高，修 bug 也很快。

真是太爽了。

更夸张的是现在深度求索还在搞活动，token 打 25 折，青天大老爷啊，这跟白送有什么区别！

## 规划专栏的写作

这周我在写专栏的时候遇到了一个问题。

这周我写的文章名字叫《主观主义是一种什么性质的问题》，在写完之后，我发现我陷入了泥泞之中。

我深度分析了主观主义的性质和由来，最后得出主观主义是一种源于认识论的问题，并拿它和唯物主义认识论进行对比。

写到最后的时候，我发现我写的这些东西对于读者而言只是空中楼阁。

因为想要系统性地认识这些错误，就必须先要有唯物主义的认识论和世界观，而我目前呈现的内容里除了系统性的分析，却没有对这些最基础的东西进行呈现。

所以，本来还准备继续写长篇大论的我收了手，点到即止。

我准备在未来一到两个月里，专注于《实践论》和《矛盾论》两篇文章的拆解。过去只要有人问我应该如何阅读《毛选》，我都会说，可以先读这两篇，所以，这两篇在整个专栏中都有着承前启后的作用。

我不知道我能做到多好，但是我必须这么做，也应该这么做。

## 玩洛克王国

虽然这个词条放在这里会有些奇怪，但是这周我的确花了一些时间来玩洛克王国。

小时候我就是洛克王国页游的忠实玩家，只是上了初中之后就没再玩过了，而现在除了手游，作为情怀党，我还是来玩了。

这周我什么也没干，就是在里面刷异色精灵，刷了极光千兽、大耳帽兜、月牙雪熊、落陨星兔的异色，顺便还获得了一只贝瑟的异色。

但是坦白说，挺空虚的，我不知道在这个过程中获得了什么。

我对游戏的态度就是这样，很矛盾，既不能完全不玩，又不能专注地去玩。

仔细思考一下，我玩游戏不喜欢看游戏剧情，有跳过键我是必跳的，没有跳过键我也会疯狂按空格。

坦白说，一个游戏是用剧情来串起所有的建模、美术等等，如果不看剧情，剩下的就只有纯粹的玩法——抓宠物、战斗、探索等等，但是我对这些东西都不太感兴趣。

过去我最爱玩的是肉鸽类和建造类游戏，前者是有非常爽的割草感，后者则是沉迷在一种逻辑规划的快感中无法自拔。

归根结底，现在我的游戏时间对比以前已经降低很多了，我认为游戏的唯一问题就是太花时间了。

现在我的小黑盒上显示的时间是 300 多个小时，而我的好友嘉华君是 3000 小时，在我看来，他玩的其实也不算多，因为我曾经见过一款游戏时长就高达数千小时的人。

根本不敢想象。

## 有氧运动

上一周休息了五天，状态恢复了不少，这周开始复健了，但是依旧没有进健身房，而是每天在家骑骑行台。

骑了五天之后，我发现现在我的有氧能力简直退步了不止一点半点。

我用 140W 的功率持续输出一个小时，心率就已经来到了 150，并且有一两天，仅仅只是输出了 50 分钟左右，我就觉得自己没有力气了。

这简直不可思议，我为什么变得这么弱？回想去年我还是可以用 200W 持续输出一个小时的人。

也正是因为这种不可思议，我才没有往健身房走，而是选择持续训练一段时间骑行台，我想看看多练几天表现会不会有提升。

## 散步

这周我开始有意识地在晚餐后留出一段时间来散步。

坦白说，我是在 cos 乔布斯。在过去我没有散步的习惯，而在读了《乔布斯传》之后，我才知道乔布斯很喜欢和别人一边散步一边交流，因为在散步的时候往往会出现很棒的灵感。

后来我在 Dan Koe 的文章里也读到，他把散步比作是冥想的一种：

> 如果实在写不出来，不妨学学乔布斯或塔伦蒂诺：停下来，去散散步，做点别的事情。你的大脑会在后台继续工作，灵感往往会在不经意间迸发出来，这就是所谓的「啊哈！」时刻。把这些时刻分享出去，总有人会受益。 
> 
> ——Dan Koe

虽然我现在还没有感受到这种灵光一闪的感觉，但是现在看来，出门散散步其实不算一件坏事。

- 我有时间，这段时间如果不拿来散步，我基本只能拿来刷短视频或者玩游戏了，用散步来消磨这段时间，其实很好。
- 平常很多时候虽然我都在进行锻炼，但其实热量消耗还是不够的，散一个小时的步，可以有效增加活动量。

所以，何乐而不为。

现在每天晚上七点多，我就会出门散步。散步的时候，我会尽量克制自己看手机，带上耳机听音乐，把注意力放在路过的人、音乐、建筑、植物、风里。

其实一个小时很快就过去了，我最多只能走 4 公里多一点，完成之后，即便没有新的灵感，但是身体的体验是很舒适的。

为了灵感而去散步，未免太功利了。

不过唯一遗憾的是，要是在散步的时候有一个人和自己交流就好了。
