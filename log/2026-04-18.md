### [12:27:11] 根因确认：模型调用超时

**根因分析**：
- CF Worker 未配置直接 API key（DEEPSEEK_API_KEY/OPENAI_API_KEY），走代理模式
- 代理目标为 Vercel 上游（zlxamx-github-io.vercel.app）
- Vercel API 内部 callOpenAI/callDeepSeek 硬编码 25 秒超时
- 真实问题需要模型生成完整分析（900 max tokens），超过 25 秒
- CF Worker 同样 25 秒超时，两层超时同时触发 → 504/500 → 前端显示"发送失败"

**验证数据**：
- "测试"（rejection，短输出）：7 秒返回 200 ✓
- "我该不该辞职？"（full analysis）：25 秒超时 504 ✗

**修复方向**：
1. 增加 Vercel 函数超时配置（vercel.json maxDuration: 60）
2. 让 Vercel 内部模型超时可配置，提升至 55s
3. 同步提升 CF Worker REQUEST_TIMEOUT_MS 至 55000
4. 根本修复：在 Cloudflare 配置 DEEPSEEK_API_KEY secret，绕过 Vercel 中转

- curl 不受 JS 超时限制，所以 curl 测试成功

- assets/js/dialectics.js: createRequestSignal(15000) → createRequestSignal(45000)
